# 二、当前 UI 技术基线与审计结论

当前项目继续采用：

- 静态 HTML / CSS / JavaScript；
- GitHub Pages；
- PWA；
- LocalStorage + SAVE_VERSION 2；
- 不使用 React / Vite 等构建链。

当前界面已有：

- 520px 最大宽度的手机主容器；
- 顶部品牌与等级 / 境界 / 声望 / 银两资源区；
- 江湖 / 队伍 / 武学 / 行囊 / 记录五项固定底部导航；
- 世界页主任务、成长信息、节点地图；
- 队伍卡片；
- 武学卡片；
- 真实行囊、装备、消耗品、秘籍语义；
- 地点 Sheet、商店 Sheet、战斗 Sheet；
- Toast；
- PWA 安全区适配；
- ≤380px 的部分地图适配。

当前主要优化目标不是“修复不可玩”，而是解决以下结构性问题：

1. 页面信息密度与层级标准不完全统一；
2. 字号、间距、圆角、卡片状态等视觉规则较分散；
3. 顶部资源区、底栏、按钮、Sheet 等全局组件仍需统一交互规范；
4. 地图依赖 `nth-child + absolute` 坐标，扩展地点时维护成本偏高；
5. 当前小屏适配覆盖面有限，需要系统验证 320～520px；
6. 战斗信息较多，需要进一步区分“当前行动 / 角色状态 / 可操作区 / 日志”；
7. 行囊、武学、队伍、记录页面虽可用，但缺少统一的信息层级与空状态规范；
8. 当前 CSS 已经进入需要整理设计 token 与组件层级的阶段，但不需要迁移技术栈。

# 四、设计与实现原则

## 1. 手机优先

主验收场景仍是手机 PWA。

桌面浏览器只要求：

- 不破版；
- 居中；
- 可操作。

不为桌面端单独设计复杂布局。

## 2. 先信息架构，后视觉润色

优化顺序：

```text
信息层级
→ 操作路径
→ 响应式
→ 组件一致性
→ 视觉细节
```

禁止先堆光效、渐变、动画，再补交互。

## 3. 不用 UI 优化掩盖底层重构

v0.4 / v0.5 已冻结的：

- battle 核心；
- combatant 构造；
- inventory State；
- ITEM_CATALOG；
- equipment；
- consumable；
- shops；
- SAVE_VERSION 2；

均不得因为“界面方便”随意改写。

UI 只消费现有数据和公开接口。

## 4. 不提前进入美术阶段

允许：

- CSS 颜色；
- CSS 渐变；
- 线条；
- 简单几何纹理；
- 文字符号；
- 现有 SVG 图标；
- CSS 动效。

不允许：

- 正式人物立绘；
- 大地图背景插画；
- 技能动画素材；
- 大规模图片资源。

## 5. 可扩展性优先于“这版刚好能摆下”

任何布局不得依赖当前恰好只有：

- 11 个地点；
- 4 个角色；
- 当前几门武学；
- 当前几件物品。

新增地点 / 武学 / 物品后，不应必须重新手调整页布局。

## 6. 操作反馈必须明确

可点击、禁用、已选中、成功、失败、危险操作必须有不同反馈。

关键按钮最低目标触控高度：44px。

不允许只有颜色变化而没有文字 / 状态辅助信息。

# 七、阶段 C：世界首页与节点地图 UX

## 目标

让玩家打开游戏后，能快速回答：

1. 我现在在哪个阶段？
2. 我下一步能做什么？
3. 我当前成长状态是什么？
4. 哪些地点能进？

## 任务

优化世界页：

- 主线 / 自由活动状态优先展示；
- 成长信息压缩为可快速扫描的摘要；
- 任务按钮与地图形成明确上下游；
- 已完成第一季时不再让页面看起来像仍有强制主线；
- 地点锁定 / 可进入 / 有事件三种状态可辨识。

地图层必须改掉对地点数量高度敏感的纯 `nth-child` 维护方式。

可以采用：

- 每个地点自带 UI 坐标数据；或
- 独立 map-layout 数据；

但不得把真实剧情条件写进 CSS。

地图本阶段只做：

- 节点布局；
- 路线 / 区域的抽象呈现；
- 状态层级；
- 点击体验；
- 小屏适配。

不做正式地图背景美术。

## 完成标志

新增 / 调整一个地点位置时，不需要继续依赖 CSS `nth-child` 手工排序；320～520px 都能点击全部关键地点。

# 十五、版本与存档策略

# 最终判定

v0.6 的完成标准不是“界面更花哨”。

真正完成标准是：

> **玩家在手机上能够快速看懂当前状态、下一步目标和可操作对象；世界、队伍、武学、行囊、商店、战斗与记录使用统一的视觉和交互语言；320～520px 无关键破版；同时所有 v0.3～v0.5 功能和存档继续稳定。**

**角色立绘、地图背景、技能特效等正式美术资源阶段。**
