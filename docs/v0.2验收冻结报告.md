# 《不良人：江湖行》v0.2 验收冻结报告

> 验收日期：2026-08-14  
> 上位依据：《不良人：江湖行》v0.2 技术实施任务书  
> 冻结目标：v0.2.x stable

---

## 一、阶段结论

v0.2 的目标不是增加大量正式剧情，而是建立可长期承载第一季至第七季内容的群侠传式江湖 RPG 基础框架。

截至本次验收：

- State v2 已完成。
- v0.1 → v0.2 存档迁移已完成并经真机旧存档验证。
- 等级、经验、修为、境界、声望已进入统一成长链。
- 人物关系与同行状态已经解耦。
- 通用条件引擎与通用事件引擎已经完成。
- 隐藏事件可以只通过增加事件数据实现，不需要修改 app.js 主流程。
- 原 v0.1 序章事件已经迁入事件系统。
- 战斗可以由事件启动，胜负结果回传事件系统。
- 第一季从序章到终局的骨架路径已经真机跑通。
- PWA / GitHub Pages / Service Worker 更新链路已经跑通。
- 存档读取增加结构归一化，避免可解析但结构损坏的存档造成永久白屏。
- GitHub Pages 工作流已加入 JavaScript 语法和 manifest JSON 静态检查，检查失败则不允许部署。

因此，v0.2 基础框架满足冻结条件。

## 三、真机验收记录

已实际验证的关键链路包括：

1. 手机从旧版本自动更新至 v0.2 系列。
2. v0.1 旧进度迁移后保留等级、银两、地图解锁等状态。
3. 玩家通过练功获得修为，并由无品突破至小星位。
4. 人物事件改变蚩梦好感后，可以影响下一人物事件出现。
5. 满足条件后出现隐藏事件“废驿下的铜牌”，证明纯事件数据可以驱动新隐藏内容。
6. 序章与藏兵谷事件由事件系统继续推进。
7. 第一季骨架从渝州 / 藏兵谷继续推进至玄冥教、幻音坊、通文馆、龙泉与第一季终局。

## 四、静态验收机制

GitHub Pages 部署工作流现已在正式发布前执行：

```text
node --check sw.js
node --check src/*.js
manifest.webmanifest JSON parse
```

只有静态检查全部通过，才继续部署 GitHub Pages。

## 五、v0.2 冻结规则

从本报告生效起，v0.2 基础框架进入冻结状态。

后续原则：

1. 不因临时聊天需求随意重构 State / 条件 / 事件 / 存档核心结构。
2. 新增第一季正式剧情优先通过事件数据与现有系统实现。
3. 如果后续内容确实暴露架构缺陷，先记录问题并提出任务书修改建议，不直接打乱路线图。
4. 世界地图、美术、战斗高级机制、复杂装备等仍按后续既定阶段处理。
5. v0.2 冻结后，下一工作阶段为“第一季正式内容填充”，不是继续堆底层功能。
