# 《不良人：江湖行》v0.7 第一批战斗站姿生成规格

> 阶段：v0.7 Stage C  
> 原则：网上找优先、生成兜底；网络透明武侠人物素材已完成初筛，但现有可用免费候选普遍偏 VN / 动漫 / 像素风，与 Stage B 已确认的 2.5D 半写实主视觉差异明显，因此不为节省生成次数强行混用。

## 本轮最小生成量

只生成 3 张核心友方战斗站姿：

1. `player-battle`
2. `chimeng-battle`
3. `nvdi-battle`

第一季普通敌人不占用户生图额度，先采用统一暗色江湖剪影 / 阵营造型完成 Stage C 最小敌方视觉；后续若进入更高美术精修版本，再决定是否替换。

---

# 一、统一技术要求

三张图必须：

- 与 Stage B 已通过的主立绘保持同一人物身份和美术体系；
- **透明背景 PNG / WebP**，不要场景背景；
- 竖向全身或至少从头到脚接近完整；
- 角色脚底不要被裁掉；
- 画面四周留出少量安全边距；
- 3/4 侧身站位优先，不要完全正面证件照姿势；
- 武器 / 手部完整，不要裁切；
- 2.5D 半写实国风武侠手游质感；
- 光源和材质细节与已通过主立绘尽量统一；
- 不要文字、Logo、水印、UI、地面、复杂光圈；
- 不要重新设计人物脸、发型、服装主结构；
- 目标是“同一个角色切换成战斗站姿”，不是重新生成一个相似人物。

推荐输出：

```text
透明 PNG
长边约 1200～1800px 原图
```

项目入库时再统一压缩为 WebP。

---

# 二、无名少侠 `player-battle`

请把已提供的“无名少侠主立绘”作为强参考原型，生成同一人物的透明背景战斗站姿。

固定特征：

- 20 岁左右中国青年游侠；
- 黑发束发 / 半束发；
- 深蓝灰、墨黑、暗青实战型江湖劲装；
- 布料、皮革、护腕、腰带等细节保持原立绘体系；
- 佩剑；
- 英气、机敏、有少年侠气，不是霸总脸或仙侠圣子。

战斗姿势：

- 3/4 侧身；
- 身体略压低重心；
- 一手持剑或准备拔剑，一手自然保持平衡；
- 有“下一秒会前冲”的待机感；
- 不做夸张大招动作，作为日常战场 idle / 普攻基础站姿使用。

---

# 三、蚩梦 `chimeng-battle`

请把已通过的“蚩梦主立绘”和蚩梦原型参考作为强参考，生成**蚩梦本人**的透明背景战斗站姿。

固定特征：

- 紫粉色头发、刘海和发型结构；
- 苗疆 / 娆疆银饰头冠；
- 紫、粉紫、深紫服装体系；
- 苗疆饰品、护臂、腰饰等识别元素；
- 灵动、俏皮、狡黠，不改成普通 AI 美女或冷脸御姐。

战斗姿势：

- 3/4 侧身；
- 重心轻盈；
- 手持短笛 / 毒镖 / 蛊术准备动作均可，但优先保持与当前角色代表视觉一致；
- 姿态要有速度感和灵巧感；
- 不做全屏大招动作，留给 Stage D Cut-in。

---

# 四、女帝 `nvdi-battle`

请把已通过的“女帝主立绘”和女帝原型参考作为强参考，生成**女帝本人**的透明背景战斗站姿。

固定特征：

- 长黑发；
- 金色冠饰 / 发饰；
- 紫红、绛红、黑金服饰；
- 岐王 / 上位者气场；
- 冷艳尊贵但不是面瘫模板脸；
- 保持当前主立绘的人脸和服装识别度。

战斗姿势：

- 3/4 侧身或轻微正侧结合；
- 姿态稳定、有压迫感；
- 手持剑或进入剑势准备状态；
- 袖摆和长发可有轻微动态；
- 不做全屏岐王斩大招动作，Stage D 会单独制作 Cut-in。

---

# 五、给生图模型的统一补充句

建议三张图都附加：

> 我同时上传该角色已经通过的正式主立绘。请把这张主立绘当作角色身份锁定图：脸、发型、发色、头饰、服装主设计、身材比例和整体气质必须保持一致，只改变为透明背景的战斗待机姿势。不要自由发挥成另一个角色。

---

# 六、Stage C 敌方策略

当前第一季敌方：

- 玄冥教探子
- 玄冥教力士
- 黑无常
- 焦兰殿禁卫

本阶段先采用项目内统一的暗色半写实剪影 / 阵营轮廓方案作为最小战场视觉：

- 探子：轻装、短兵、速度型轮廓；
- 力士：宽肩、重装、掌法型轮廓；
- 黑无常：高瘦、阴寒、爪功型轮廓；
- 禁卫：甲胄、横刀、宫廷卫士轮廓。

这些敌人仍由 `art registry` 管理，并保留未来替换正式立绘的接口。Stage C 不因杂兵美术扩大用户生成负担。
