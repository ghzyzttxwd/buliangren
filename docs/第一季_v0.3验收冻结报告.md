# 三、阶段 I 发现并修复的阻断问题

## 1. 全新存档声望门槛卡死

此前 v0.3 的后半段声望门槛主要依据一路从 v0.2 测试版本升级的真实旧存档调试。

自动新档测试首次运行后发现：

```text
chapter=s1_tongwenguan
quest=查清通文馆的真正目标
reputation=138
```

但【馆主之令】旧门槛为 190，导致：

> 老测试存档可通关，但真正的全新存档会在通文馆永久卡住。

处理方式：

- 不给玩家凭空补送大额声望；
- 不新增强制刷声望按钮；
- 不改变主线顺序；
- 仅校正第一季后半段正式事件的 `reputationGte` 门槛，使正常完成当前可见自由内容的新档可以自然推进。

最终新档自动通关后声望为 252。

最终门槛校正集中记录于：

```text
src/events-s1-balance.js
```

## 2. 冻结前旧 UI 占位

修复：

- 江湖首页不再永久写死“第一季 · 序章 · 风起渝州”；
