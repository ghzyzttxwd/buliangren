# 一、统一风格

目标不是纯二次元纸片，也不是写实真人照片。

统一方向：

```text
中国武侠 / 国风移动游戏角色立绘
2.5D 半写实
人物五官清晰
服装材质有质感但不过度堆甲片
暗色江湖氛围
角色本身有明显主色
适合深色 UI
```

参考气质：移动端国风武侠 RPG 的正式角色立绘；人物要有“能直接放进游戏角色页”的完成度。

禁止：

- 照片感真人；
- Q 版；
- 纯日系校园动漫；
- 仙侠白衣飘飘堆仙气；
- 夸张网红脸；
- 大量发光首饰；
- 复杂文字 / logo / 水印；
- 背景抢人物；
- 把武器横在脸前；
- 多余肢体 / 手指错误。

输出建议：

```text
竖图
约 3:4 或 4:5
长边 1200～1600px 左右即可
人物至少到大腿 / 膝上
优先纯色、透明或非常干净的暗色背景
PNG / WebP
```

如果生成器不能透明背景，使用深灰 / 深蓝灰简单背景，后续再统一抠图与压缩。

# 二、player-portrait｜无名少侠

## 角色定位

第一季玩家原创主角。不是名门贵公子，也不是仙门圣子。

关键词：

```text
年轻中国男性游侠
约 20 岁上下
黑发束起
干净利落
有江湖气但不邋遢
普通出身感
沉稳但不冷脸
佩剑
```

服装：

- 深蓝灰 / 墨黑为主；
- 少量暗金或棕色皮革细节；
- 轻便武侠劲装；
- 不穿重甲；
- 不穿华丽皇族服饰；
- 不出现明确门派 logo。

表情：

- 警觉；
- 有年轻人的生命力；
- 不面瘫；
- 不邪笑；
- 不霸总冷脸。

构图：

- 3/4 身；
- 身体略侧；
- 一只手自然靠近剑柄即可；
- 脸必须清楚；
- 轮廓适合后续裁进队伍卡片。

建议提示词核心：

```text
young Chinese wuxia swordsman, wandering martial artist, dark navy and charcoal martial outfit, tied black hair, simple sword at waist, grounded jianghu feeling, alert and lively expression, semi-realistic 2.5D Chinese mobile RPG character illustration, thigh-up portrait, clean dark background, detailed fabric, no heavy armor, no text, no watermark
```

文件目标：

`assets/art/characters/portraits/player-portrait.webp`

# 三、chimeng-portrait｜蚩梦

## 造型基准

以《不良人》/《不良人3》官方公开视觉作为人物识别参考，不直接复制官方图片构图。

必须保留的高识别元素：

- 紫粉 / 桃紫色头发；
- 苗疆 / 娆疆感银饰头冠；
- 紫色系服饰；
- 灵动、古灵精怪；
- 蛊术 / 毒术气质；
- 年轻、活泼，不做阴沉毒女。

服装允许重新设计，但要做到“第一眼仍然知道是蚩梦”。

构图：

- 3/4 身；
- 动态比主角略强；
- 可有少量蝴蝶 / 紫雾作为边缘点缀；
- 不要让特效遮住人物轮廓；
- 不做大招姿势，这只是主立绘。

建议提示词核心：

```text
Chi Meng inspired canonical character from Chinese wuxia animation, recognizable pink-purple hair, ornate silver Miao-style headpiece, purple ethnic martial outfit, lively mischievous expression, poison and gu atmosphere, elegant but agile, semi-realistic 2.5D Chinese mobile RPG character illustration, thigh-up portrait, clean dark violet background, subtle butterfly and purple mist accents, no text, no watermark
```

# 四、nvdi-portrait｜女帝

## 造型基准

以《不良人》/《不良人3》官方公开视觉作为人物识别参考，不直接复制官方图片构图。

必须保留的高识别元素：

- 女王 / 岐王气场；
- 长黑发；
- 华贵金色冠饰；
- 紫红 / 绛红 / 金色系服饰；
- 威严、冷艳，但不是没有表情；
- 明显高位者气质。

服装可以适度简化，避免在手机小图里变成一团细节。

构图：

- 3/4 身；
- 身姿挺拔；
- 可轻扶衣袖或持剑，但不要让武器抢脸；
- 背景用暗红 / 暗紫即可；
- 不做大招姿势。

建议提示词核心：

```text
Empress / Nvdi inspired canonical character from Chinese wuxia animation, regal Chinese female ruler, long black hair, elaborate gold crown ornament, crimson purple and gold martial court attire, commanding elegant presence, proud focused expression, semi-realistic 2.5D Chinese mobile RPG character illustration, thigh-up portrait, clean dark crimson background, detailed silk fabric, no text, no watermark
```

官方视觉参考页：

- https://blr3.nbjoy.com/news/10343.html

文件目标：

`assets/art/characters/portraits/nvdi-portrait.webp`

# 五、验收条件

三张图进入游戏前统一检查：

1. 三人风格是否像同一款游戏；
2. 手机宽度下脸部仍清楚；
3. 人物轮廓不被背景吃掉；
4. 蚩梦 / 女帝人物识别没有明显跑偏；
5. 主角没有变成仙侠圣子或华丽贵公子；
6. 没有文字、水印、错误肢体；
7. 文件体积压缩后合理；
8. 图片失败时仍可回退到现有“侠 / 梦 / 岐”占位字。
