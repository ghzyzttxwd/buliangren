# 《不良人：江湖行》v0.7 美术资源来源表

> 用途：记录 v0.7 正式美术、候选素材与参考来源。  
> 原则：网上找优先，生成兜底；正式入库素材必须本地化，不使用网络热链。

## 状态说明

- `ready`：授权 / 来源清晰，已可进入正式加工与本地化。
- `candidate`：候选资源池，使用具体文件前仍需确认单图授权或适配性。
- `reference-only`：只用于角色造型、配色、构图、演出参考，不默认直接打包。
- `generate-if-needed`：网上素材不足或不适合时才进入生成队列。
- `deferred`：不属于当前第一批生产范围。

### Stage B 网络筛选结论（2026-08-17）

1. **玩家原创主角**：存在授权清晰的免费 / 低价东方武侠角色素材，但目前筛到的免费候选与本项目暗色、较成熟的移动武侠视觉不够统一；不为了省一次生成硬塞最终版。
2. **蚩梦**：官方高质量宣传 / 壁纸资料足够作为造型参考，但没有找到明确允许第三方把图片重新打包进本游戏的授权，因此主立绘不直接使用官方图片。
3. **女帝**：同上。官方壁纸适合作为服饰、冠饰和色彩参考，不直接作为项目分发资产。
4. 因此第一批正式主立绘进入最小生成队列：`player-portrait / chimeng-portrait / nvdi-portrait`。
5. 生成只解决这三张 Stage B 必需图，不顺手生成战斗站姿或 Cut-in；后两类分别留给 Stage C / D。

## 五、生成队列规则

只有满足任一条件才进入生成：

- 没有合适网络素材；
- 可见素材授权不清；
- 必须保持原创；
- 现成图无法做透明战斗站姿；
- Cut-in 需要专门构图；
- 风格差异已经明显影响整体观感。

Stage B 三张主立绘已经生成并正式入库，不再处于 `generate-if-needed` 状态。

Stage C / D 的战斗站姿与 Cut-in 暂不提前生成。

不批量预生成未来人物。
