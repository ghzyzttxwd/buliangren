# 《不良人：江湖行》第一季原作大事件基准表

> 文档性质：第一季正式内容阶段 A 的原作历史锚点基准  
> 上位依据：《第一季正式内容实施任务书 V1.0》  
> 核对对象：2014 年网络动画《画江湖之不良人》第一季（54 集）  
> 用途：锁定“大历史锚点”，不是逐集复刻表，也不是最终游戏事件表。  
> 状态：阶段 A 基准锁定稿 V1.0

---

## 一、使用规则

1. 本表只锁定第一季必须尊重的原作大方向。
2. 游戏玩家是原创主角，不替代李星云、陆林轩、姬如雪、张子凡等原作人物完成其核心历史行为。
3. 原作核心结果保持不变；玩家可以介入过程、支线冲突、情报获取、救援、局部战斗、人物关系和隐藏事件。
4. 不复制动画原对白，不逐集复刻。
5. 若后续发现本表与更可靠的一手资料冲突，必须先修订本表，再修改正式剧情代码。
6. 本表的“玩家可介入空间”属于游戏设计边界，不属于原作事实。

# 二、第一季 8 个核心大事件基准

## 1. 渝州初入江湖

**对应游戏阶段**

```text
s1_prologue → s1_yuzhou
```

**原作锚点**

李星云与陆林轩成年后离开剑庐进入江湖。渝州一带已经存在玄冥教、幻音坊等势力活动；李星云、陆林轩在这一阶段与姬如雪、张子凡等人发生交集。黑白无常重新确认李星云、陆林轩与当年旧事有关后，玄冥教的追查由普通追捕升级，五大阎君开始向渝州集结。

**涉及人物**

- 李星云
- 陆林轩
- 姬如雪
- 张子凡
- 黑无常常昊灵
- 白无常常宣灵
- 孟婆
- 五大阎君（作为升级后的玄冥教压力）

**涉及势力**

- 玄冥教
- 幻音坊
- 通文馆（经张子凡开始进入视野）

**主要地点**

- 渝州及周边
- 剑庐（作为李星云、陆林轩进入江湖前后的原作背景锚点）

**前置大事件**

原作童年背景：陆佑劫、李焕被黑白无常所害，阳叔子收留李星云与陆林轩。游戏不需要让玩家重演该童年事件，但不能改写其既定结果。

**事件结果**

- 李星云、陆林轩正式进入江湖。
- 姬如雪、张子凡与李星云一行产生持续关系。
- 玄冥教确认目标并加大追查力度。
- 第一季从局部渝州事件进入多势力关注阶段。

**必须保持的原作方向**

- 李星云与陆林轩的师门与童年历史不由玩家改写。
- 李星云、陆林轩必须进入江湖。
- 玄冥教必须成为早期持续追查方。
- 姬如雪、张子凡必须进入原作人物关系网络。

**玩家可介入空间**

- 玩家为什么来到渝州。
- 玩家先接触玄冥教、姬如雪、张子凡中的哪条边缘线索。
- 帮助百姓、追踪探子、救援路人、获取情报等原创事件。
- 玩家可以与李星云一行产生“擦肩、协助、并肩处理局部冲突”等关系，但不能替代他们完成原作初遇与核心身份事件。

**资料依据 / 核对状态**

- 动画第一季总剧情简介：李星云、陆林轩下山后结识姬如雪、张子凡，并因龙泉剑卷入多势力争夺。
- 动画第 8 集：黑白无常确认二人与旧事有关，孟婆派五大阎君支援。
- 动画第 9、11 集：五大阎君陆续进入渝州，玄冥教压力升级。
- 核对状态：**已锁定**。

## 2. 李星云身份与龙泉剑成为天下焦点

**对应游戏阶段**

```text
s1_yuzhou → s1_xuanming
```

**原作锚点**

玄冥教利用阳叔子/剑庐线索逼李星云回返，剑庐冲突升级为李星云与多名阎君的大战。李星云重伤后被姬如雪救走，随后被上官云阙带往藏兵谷。不良帅袁天罡正式与李星云见面，要求其承担复唐身份责任但遭拒；其后龙泉剑交到李星云手中，李星云的真实身份又被有意扩散，使他从“被追杀的江湖少年”升级为各方势力争夺的政治核心。

**涉及人物**

- 李星云
- 陆林轩
- 姬如雪
- 张子凡
- 阳叔子
- 上官云阙
- 袁天罡 / 不良帅
- 四大阎君及黑白无常

**涉及势力**

- 不良人
- 玄冥教
- 幻音坊
- 通文馆

**主要地点**

- 剑庐
- 藏兵谷

**前置大事件**

- 渝州追查升级。
- 玄冥教将阳叔子/剑庐作为逼出李星云的重要线索。

**事件结果**

- 李星云经历剑庐大战并重伤。
- 李星云被带入藏兵谷并正式面对不良帅。
- 袁天罡要求李星云复唐，李星云拒绝。
- 龙泉剑进入李星云手中。
- 李星云的李唐身份成为后续各势力行动的核心变量。

**必须保持的原作方向**

- 玩家不能替代李星云成为李唐皇室核心继承人。
- 袁天罡与李星云“复唐 / 拒绝复唐”的核心矛盾必须保留。
- 龙泉剑不能改成由玩家长期持有并取代李星云的历史作用。
- 李星云真实身份必须在第一季中成为各大势力公开争夺的重要原因。

**玩家可介入空间**

- 玩家可以参与剑庐外围、追兵截击、伤员救援、情报误导等局部事件。
- 玩家可以较早或较晚知道李星云身份，但不能改变身份本身。
- 玩家可以因声望/关系决定是否卷入藏兵谷外围的不良人支线。
- 玩家不能代替袁天罡向李星云作出复唐要求，也不能替李星云作答。

**资料依据 / 核对状态**

- 动画第 23～25 集：剑庐冲突、四阎君围攻、李星云重伤。
- 动画第 26 集：姬如雪与重伤李星云被上官云阙带往藏兵谷。
- 动画第 29 集：袁天罡现身，要求李星云复唐，李星云拒绝。
- 动画第 31 集：袁天罡将龙泉剑交给李星云，并把其真实身份广布江湖。
- 核对状态：**已锁定**。

## 3. 玄冥教行动扩大

**对应游戏阶段**

```text
s1_xuanming
```

**原作锚点**

玄冥教对李星云/龙泉剑的追捕由黑白无常层级升级至五大阎君，再进一步上升到冥帝朱友珪亲自进入棋局。与此同时，黑白无常与阎君之间发生严重内斗，冥帝采取“坐观其斗”的态度；玄冥教内部还存在不良人长期潜伏，为第一季后期的反转埋下基础。

**涉及人物**

- 冥帝朱友珪
- 孟婆
- 黑白无常
- 五大阎君
- 温韬
- 水火判官
- 李星云一行

**涉及势力**

- 玄冥教
- 不良人（潜伏线）

**主要地点**

- 渝州分舵
- 玄冥教总舵及其行动范围
- 后期延伸至洛阳

**前置大事件**

- 李星云、龙泉剑、李唐身份的重要性不断提高。
- 黑白无常前期屡次失手。

**事件结果**

- 玄冥教内部权力与生存竞争全面升级。
- 黑白无常与多名阎君形成生死内斗。
- 冥帝朱友珪从幕后势力首领进入第一季后期核心反派位置。
- 孟婆、温韬等“不良人潜伏者”逐步显露。

**必须保持的原作方向**

- 玄冥教不能被玩家在第一季中提前整体消灭。
- 黑白无常与阎君内斗是玄冥教内部线的重要组成。
- 冥帝朱友珪必须进入第一季终局线。
- 不良人长期潜伏玄冥教的反转必须保留。

**玩家可介入空间**

- 玩家可以接触不同层级玄冥教成员，形成敌对、放过、追踪、偷听、救援等局部结果。
- 玩家可以影响某些原创玄冥教外围 NPC 的去留。
- 玩家可以提前发现“玄冥教内部不对劲”的迹象，但不能直接揭穿孟婆等核心卧底身份并改变终局。

**资料依据 / 核对状态**

- 动画第 8、9、11 集：玄冥教由黑白无常升级到五大阎君追捕。
- 动画第 26 集：冥帝正式进入主线。
- 动画第 39、44、47～49 集：玄冥教内部斗争、温韬/孟婆潜伏线、冥帝坐山观虎斗及后续计划。
- 核对状态：**已锁定**。

## 4. 幻音坊介入

**对应游戏阶段**

```text
s1_huanyinfang
```

**原作锚点**

幻音坊从姬如雪个人任务逐步升级为女帝直接部署。女帝先要求姬如雪接近李星云并夺取龙泉剑，随后因局势扩大派出九天圣姬继续行动；在确认李星云真实身份后，幻音坊对李星云的价值判断从单纯“夺剑”升级为政治层面的拉拢与利用。

**涉及人物**

- 女帝
- 姬如雪
- 梵音天
- 妙成天
- 玄净天
- 李星云

**涉及势力**

- 幻音坊 / 岐国一方

**主要地点**

- 渝州及李星云行进路线
- 幻音坊势力活动范围

**前置大事件**

- 龙泉剑与李星云逐渐成为争夺核心。
- 姬如雪与李星云形成持续的个人关系。

**事件结果**

- 幻音坊正式成为争夺李星云/龙泉剑的重要势力。

**玩家可介入空间**

- 玩家与女帝的个人关系可以从“听闻 / 被注意 / 正式相识”逐步建立，但不得把玩家写成取代李星云的核心政治筹码。
- 玩家可选择帮助或阻碍幻音坊的局部行动，从而形成关系 Flag 与好感差异。

**资料依据 / 核对状态**

- 动画第 14 集：女帝命姬如雪接近李星云并夺取龙泉剑。
- 动画第 31～33 集：女帝派梵音天行动，并得知李星云真实身份。
- 动画第 39 集：女帝继续派妙成天、玄净天接近李星云。
- 幻音坊组织资料：第一季核心目标围绕龙泉剑与李星云展开。
- 核对状态：**已锁定**。

## 5. 通文馆介入

```text
s1_tongwenguan
```

张子凡本身即是通文馆少主/李嗣源义子，使通文馆很早就与李星云一行发生交叉。李嗣源随后明确要求把李星云带回通文馆，并派李存忠、李存孝等人行动。随着李星云身份公开，通文馆从“抓人/带回”进一步升级为政治拉拢；其与岐国一方既竞争又会因共同对抗玄冥教而阶段性合作。

**涉及人物**

- 张子凡
- 李嗣源
- 李存忠
- 李存孝
- 李星云
- 陆林轩
- 岐国/幻音坊一方代表

**涉及势力**

- 通文馆
- 幻音坊 / 岐国一方
- 玄冥教（共同对手之一）

**主要地点**

- 通文馆势力范围
- 李星云一行活动区域

**前置大事件**

- 张子凡已经与李星云、陆林轩发生持续联系。
- 李星云的身份与龙泉剑价值逐步公开。

**事件结果**

- 通文馆正式进入对李星云的争夺。
- 李嗣源的政治目的成为张子凡个人关系之外的另一层压力。
- 通文馆与岐国一方出现“既争夺、又阶段性合作”的格局。

**必须保持的原作方向**

- 张子凡与通文馆的原作身份关系不能被玩家改写。
- 通文馆必须参与争夺李星云及其政治价值。
- 李嗣源不能在第一季被玩家提前消灭或彻底退出。

**玩家可介入空间**

- 玩家可与通文馆外围成员产生敌对、交易、情报交换等支线。
- 玩家可因张子凡关系不同获得不同程度的通文馆信息。
- 玩家可以影响原创的局部抓捕/护送事件，但不能替代张子凡的原作身份矛盾。

**资料依据 / 核对状态**

- 动画第 19 集：张子凡被带回通文馆。
- 动画第 20 集：李嗣源命张子凡寻找并带回李星云。
- 动画第 33 集：岐国一方与李嗣源阶段性合作对抗玄冥教。
- 动画第 42～44 集：李嗣源与岐国一方直接拉拢李星云。
- 核对状态：**已锁定**。

## 6. 龙泉相关线索与李唐身份的政治化

**对应游戏阶段**

```text
s1_longquan（注意：这里表示“龙泉线索阶段”，不是第一季抵达龙泉秘地）
```

**原作锚点**

第一季从开篇起就以龙泉剑/龙泉宝藏传说作为争夺核心，但中后期重点进一步转为：龙泉剑、李星云李唐血脉以及各方政治野心互相绑定。袁天罡把龙泉剑交给李星云并主动扩散其真实身份后，江湖豪强与大势力对李星云的争夺全面政治化；疯道人等人物也进一步强化龙泉剑典故与李星云身份之间的关联。

**涉及人物**

- 李星云
- 袁天罡
- 上官云阙
- 温韬
- 疯道人
- 李嗣源
- 岐国/幻音坊一方
- 玄冥教核心人物

**涉及势力**

- 不良人
- 玄冥教
- 通文馆
- 幻音坊 / 岐国一方

**主要地点**

- 藏兵谷及后续江湖活动区域
- 不锁定“龙泉秘地”为第一季实体终局地点

**前置大事件**

- 李星云取得龙泉剑。
- 李星云真实身份被广泛传播。

**事件结果**

- 李星云从江湖争夺对象上升为诸侯政治筹码。
- 龙泉剑的意义从单纯兵器变成“宝藏线索 + 李唐身份”的象征。
- 岐国、通文馆等开始直接拉拢李星云。

**必须保持的原作方向**

- 龙泉剑/宝藏秘密继续是第一季的重要驱动力。
- 李星云的李唐身份必须与龙泉争夺发生政治绑定。
- 第一季不能让玩家提前真正开启龙泉宝藏并结束整个龙泉谜题。

**玩家可介入空间**

- 玩家可以获得龙泉传闻、残缺地图、假线索、地方传说等原创情报。
- 玩家可以帮助某势力取得“非核心外围线索”，但不能提前破解原作长期谜团。
- 玩家可以因声望/关系决定自己是否被卷入诸侯对李星云的拉拢局。

**重要校正：现有技术骨架与原作的差异**

现有 v0.2 骨架把 `longquan` 作为“龙泉秘地”实体地点，并把第一季终局也放在该节点。这只是技术占位。

根据第一季总剧情及第 40、42～44、53～54 集的已核对内容，第一季的后段主要是“龙泉剑/李唐身份引发的势力争夺”，而最终收束发生在洛阳焦兰殿的冥帝事件。当前没有证据支持“第一季众人已经抵达一个龙泉秘地并在那里完成终局”。

因此后续正式内容阶段应：

- 保留 `s1_longquan` 作为“龙泉线索阶段”的章节概念；
- 不把“龙泉秘地”写成第一季已经被真正发现的原作事实；
- 是否保留现有 `longquan` 地图节点，留到对应正式内容阶段按任务书处理；阶段 A 不改代码。

**资料依据 / 核对状态**

- 动画第一季总剧情：龙泉剑承载宝藏秘密并引发多门派争夺。
- 动画第 31 集：龙泉剑交到李星云手中，李星云身份被广布江湖。
- 动画第 40 集：疯道人通晓龙泉剑典故并看出李星云身份端倪。
- 动画第 42～44 集：岐国、通文馆对李星云进行政治拉拢。
- 动画第 53～54 集：第一季实际终局收束在焦兰殿/冥帝线。
- “第一季未以龙泉秘地作为终局地点”为基于上述全季结构的**阶段 A 归纳判断**。
- 核对状态：**已锁定（并记录骨架冲突）**。

## 7. 多方势力争夺与焦兰殿阴谋前夜

**对应游戏阶段**

```text
s1_longquan → s1_finale
```

# 三、第一季关键人物的历史边界

## 李星云

第一季不可改写：

- 李唐皇室后裔身份。
- 龙泉剑核心持有与历史价值。
- 袁天罡要求其复唐。
- 第一季至少两次明确拒绝复唐方向（藏兵谷与终局）。
- 第一季末不登基，选择继续江湖。

玩家定位：

> 可以成为李星云这一段历史中的同行者、盟友、偶遇之人或局部事件参与者，但不能成为“真正的皇室继承人替代品”。

## 姬如雪

第一季不可改写：

- 幻音坊出身与女帝命令关系。
- 与李星云形成重要持续关系。
- 她在李星云重伤等节点承担原作关键行动。

玩家定位：

> 可以建立独立人物关系与原创事件，但不删除她与李星云的原作主线功能。

## 张子凡

第一季不可改写：

- 通文馆少主/李嗣源义子身份。
- 与陆林轩形成重要关系。
- 其个人关系与通文馆政治任务之间存在矛盾。

玩家定位：

> 玩家可以影响张子凡对自己的信任、交换情报等，但不取代其与陆林轩及通文馆的原作主线。

## 女帝

第一季不可改写：

- 幻音坊实际决策核心。
- 幻音坊围绕李星云/龙泉剑采取多次行动。
- 李星云身份公开后，其行动具有明显政治考量。

玩家定位：

> 第一季可以建立“被注意 → 正式相识 → 初步关系”的玩家线，但不能让玩家替代李星云成为幻音坊介入天下棋局的唯一原因。

## 袁天罡 / 不良帅

第一季不可改写：

- 不良人的幕后核心。
- 推动李星云身份公开与复唐议题。
- 焦兰殿终局对朱友珪形成压倒性控制。

玩家定位：

> 第一季早期玩家原则上不应具有改变袁天罡大局安排的能力。玩家最多进入其棋局边缘，并逐渐意识到不良人的存在。

# 四、已发现的现有骨架冲突 / 待正式阶段处理

阶段 A 只记录，不改代码。

## 冲突 1：`longquan` 被当成第一季实际终局地点

现有 v0.2 骨架：

```text
通文馆 → 龙泉秘地 → 第一季终局
```

原作基准：

```text
龙泉剑 / 李唐身份引发多方政治争夺
→ 冥帝将局势引向洛阳
→ 焦兰殿终局
```

处理建议：

- `s1_longquan` 可以继续作为“龙泉线索阶段”的内部 chapter 名。
- 正式内容不能写成第一季已经开启龙泉宝藏或抵达真正龙泉秘地。
- 第一季正式终局应落在洛阳 / 焦兰殿历史锚点。
- 地图 `longquan` 节点是否隐藏、延后或改义，等阶段 F/G 执行时再按任务书处理。

## 冲突 2：现有骨架把各势力篇章写成线性“总部旅行”

原作第一季中玄冥教、幻音坊、通文馆的行动大量并行、交叉，并不是“先去玄冥教总部 → 再去幻音坊总部 → 再去通文馆总部”的顺序旅行。

处理建议：

- chapter 保留为世界阶段。
- 正式事件通过不同地点与条件并行出现。
- 不要求玩家为了进入某势力篇就必须物理到其总舵。

## 冲突 3：现有测试序章中蚩梦已经作为固定同行

2014 动画第一季的核心人物网络以李星云、陆林轩、姬如雪、张子凡及三大势力为主。蚩梦不属于第一季原作核心历史锚点。

处理原则：

- 阶段 A 仅记录，不改现有代码。
- 正式第一季内容不能把蚩梦写成“原作第一季历史中本来就在场”的人物。
- 如果项目仍希望保留蚩梦作为玩家原创线的提前登场，必须明确标注为**游戏原创介入线**，不能伪装成原作事实；具体是否保留以及如何解释，留给阶段 B 按任务书审查，不在阶段 A 擅自调整路线。

# 六、玩家原创主角的介入总边界

- 与重要人物的个人好感与 personalFlags。
- 是否参与某些外围冲突。
