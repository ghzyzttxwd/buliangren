## 一、本阶段只处理什么

本阶段只正式化：

```text
s1_prologue
s1_yuzhou
```

并完成两个第一季核心大事件槽位的落地：

1. 渝州初入江湖
2. 李星云相关事件

## 二、现有测试内容审计

### 1. `s1_yuzhou_scout` 驿道疑云

现状：玩家与蚩梦直接击败玄冥教探子，随后立即解锁藏兵谷。

判定：**替换。**

原因：

- 作为技术测试事件合格；
- 正式第一季中，玄冥教在渝州的核心目标首先围绕李星云/龙泉相关线展开；
- 玩家可以卷入外围追查，但不应打一名探子就成为整条大历史的唯一推进中心。

正式版改为“玩家发现玄冥教正在沿路搜查另一批目标”，让玩家进入同一历史而不是取代历史主角。

### 2. `s1_yuzhou_training` 城外练功

现状：无限点击获得修为与经验。

判定：**机制保留，收益模式替换。**

正式版仍允许重复练功，但只提供有限次有效收益，之后本阶段不再出现，避免无限按钮刷修为。

### 3. `s1_yuzhou_rumor` 客栈传闻

判定：**思路保留，内容正式化。**

作为玩家了解渝州当前局势的普通支线，不承担核心历史结果。

### 4. 蚩梦人物事件

判定：**保留为“游戏原创介入线”，重写文本定位。**

原则：

- 蚩梦不是动画第一季原作历史锚点中的在场人物；
- 游戏可以让她提前与原创玩家同行，但所有第一季蚩梦内容必须明确属于游戏原创线；
- 她不能替代姬如雪、张子凡、李星云、陆林轩等人的原作历史功能；
- 不再让蚩梦“认出原作本来不应由她承担的关键历史线索”来推动主线。

### 5. `s1_cangbing_mark` 石壁旧印

现状：蚩梦认出一个“岐”字，直接推动世界阶段。

判定：**删除测试剧情功能。**

藏兵谷在阶段 B 只作为“李星云被带入藏兵谷后，玩家追至外围但无法进入核心现场”的边缘观察地点。

### 6. `s1_cangbing_guard` 玄冥教力士

判定：**不再作为阶段 B 核心推进战。**

正式阶段 B 结束条件不再是“打败藏兵谷门口力士”。

### 7. v0.2 第一季 skeleton 事件

判定：**正式内容线中停用。**

原因：它们已经完成技术验收使命；继续让新玩家点击骨架占位事件会污染正式内容体验。

旧存档中已经记录的 skeleton 完成状态继续保留，不删除、不破坏；但 v0.3 正式线使用新事件 ID。

## 三、阶段 B 正式事件包

正式事件统一使用新 ID，避免旧测试存档把正式内容误判为已完成。

### 主线 1：`s1_yuzhou_formal_dark_current`

标题：**渝州暗潮**

作用：玩家原创序章正式接入第一季历史。

体验：

- 玩家与蚩梦在渝州外围发现玄冥教正在大范围盘问、追踪另一批目标；
- 玩家处理一场外围冲突；
- 明确告诉玩家：玄冥教当前真正追逐的核心并不是玩家。

结果：

- 进入 `s1_yuzhou`；
- 获得第一批声望；
- 开放本阶段自由活动与支线。

### 支线 1：`s1_yuzhou_formal_inn_rumor`

标题：**客栈里的风声**

作用：普通信息支线。

内容：从行商与江湖客口中拼出“玄冥教正在寻找一对年轻江湖人”的外围信息。

### 支线 2：`s1_yuzhou_formal_road_relief`

标题：**封路后的商队**

作用：提供非主线声望来源。

内容：玄冥教活动导致商路混乱，玩家可以帮助受困商队或处理外围追兵。

本事件可以含战斗，但类别仍为 `side`，不被首页当成强制主线。

### 自由活动：`s1_yuzhou_formal_training`

标题：**城外练功**

规则：

- repeatable；
- 本阶段最多获得 5 次有效收益；
- 每次提供少量经验/修为；
- 达到次数后不再出现在本阶段可用事件中。

### 人物事件：`s1_yuzhou_formal_chimeng_01`

标题：**蚩梦的判断**

定位：游戏原创线。

内容核心：蚩梦判断玄冥教这次在渝州大范围行动并非专门冲玩家二人而来，帮助玩家从“自己是世界中心”转向“自己卷入了更大的江湖事件”。

结果：

- 少量蚩梦好感；
- 记录一个人物 personalFlag；
- 不改变原作历史。

### 隐藏事件：`s1_yuzhou_formal_hidden_black_token`

标题：**沟渠里的黑牌**

触发：

- 已经历“渝州暗潮”；
- 修为达到一个较低阈值；
- 声望仍较低；
- 未完成事件。

目的：

- 证明隐藏事件不是主线完成链；
- 如果玩家太快把声望推高，该事件会错过；
- 获得一条玄冥教外围情报/普通物品，不改变核心历史。

### 主线 2A：`s1_yuzhou_formal_crossing`

标题：**被追逐的年轻人**

作用：正式接入“李星云相关事件”核心槽位。

内容边界：

- 玩家在渝州当前混乱中确认玄冥教真正关注的是另一名年轻人及其同行；
- 不复刻李星云、姬如雪、张子凡、陆林轩的原作具体对白；
- 玩家只参与外围冲突/短暂交叉，不替代原作角色关系。

### 主线 2B：`s1_yuzhou_formal_swordhut_aftershock`

标题：**剑庐火光**

作用：把玩家时间线接到原作剑庐大战后的世界变化。

内容边界：

- 玩家得知剑庐方向发生大战；
- 玄冥教高手已经介入；
- 那名年轻人重伤后从公开视线消失；
- 不由玩家重演李星云与四阎君核心战斗。

结果：

- 解锁藏兵谷外围路线；
- 世界进入“李星云身份/龙泉价值即将公开”的过渡阶段。

### 主线 2C：`s1_yuzhou_formal_cangbing_outer`

标题：**谷外封路**

地点：藏兵谷。

作用：阶段 B 收束事件。

内容边界：

- 玩家追查至藏兵谷外围；
- 谷内核心事件不向玩家开放；
- 玩家确认有一股隐藏力量已经接手局势；
- 不让玩家进入袁天罡与李星云的核心会面现场。

结果：

```text
world.chapter = s1_xuanming
解锁玄冥教节点
记录 stage B 完成世界事实
```

之后停止，本版本不继续开发阶段 C 正式内容。

## 四、阶段 B 声望与自由节奏

新存档建议节奏：

```text
渝州暗潮
→ 声望约 15
→ 支线 / 隐藏 / 自由活动
→ 声望达到约 30
→ 被追逐的年轻人
→ 再经过至少一个自由/支线内容
→ 声望约 45～50
→ 剑庐火光
→ 谷外封路
→ 进入 s1_xuanming
```

重点：

- 不要求精确固定上述数字；
- 旧存档若声望已经很高，可以更快满足门槛，但仍必须按新正式事件完成顺序推进；
- 新玩家不能连续只点主线按钮一路完成阶段 B。

## 五、框架例外：受控重复事件

### 已确认缺口

当前通用事件引擎：

- 支持 `repeatable`；
- State 已存在 `events.counters`；
- 但 conditions/effects 尚未使用 counter；
- 因此重复事件只能无限刷，不能满足阶段 B 的“可重复但收益受控”。

### 最小修改

只新增两个通用能力：

```text
counterLt
incrementCounter
```

示例：

```text
conditions:
  counterLt(yuzhou_training_uses, 5)

effects:
  incrementCounter(yuzhou_training_uses, 1)
```

### 影响评估

- 不改变 State 结构；`events.counters` 已存在。
- 不提升 SAVE_VERSION。
- 不修改 app.js 主流程。
- 旧存档 counters 为空时按 0 处理。
- 属于最小通用能力补齐，不扩展为每日任务/体力恢复/时间系统。

### 回归要求

修改后至少确认：

- 原 eventCompleted / reputation / realm / affinity 条件仍正常；
- 普通 instant 与 battle 事件仍正常；
- 旧存档仍可读取；
- GitHub Pages 静态检查通过。
